# Data directory

`raw/arjun_powerpack_synthetic_v3.csv.gz` is generated by `src/simulate_dataset.py` from public sensor evidence plus explicit engineering simulation assumptions.

`processed/engine_manifest.csv` contains per-engine generation metadata used to make the production split. It is metadata only and is never a model feature.

`processed/engine_splits.json` identifies engine membership in train/validation/test.
